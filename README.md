<h1 align="center"> Apple Logo Bezier Curve <h1>

A web project that demonstrates the creation of Apple logos using Bezier curves. The project includes interactive SVG, Canvas-drawn, and PNG versions of the Apple logo, integrated into a modern Apple-style webpage template.

## Features

- **SVG Logo**: Scalable vector logo with Bezier curves.
- **Canvas Logo**: Dynamically drawn Apple logo using JavaScript and Canvas API.
- **PNG Logo**: Static image version.
- **Responsive Design**: Apple-inspired webpage template with navigation, hero sections, and product cards.
- **Interactive Elements**: Hover effects and clickable logos.

## Technologies Used

- HTML5
- CSS3
- JavaScript (Canvas API)

## How to Run

1. Clone the repository:
   ```
   git clone https://github.com/zigakranjc/Apple-Logo-Bezier-curve.git
   ```

2. Open `index.html` in your web browser, or use a local server like Live Server in VSCode for better experience.

3. For development, use VSCode with the Live Server extension to auto-refresh changes.

## File Structure

- `index.html`: Main webpage with Apple product template.
- `style.css`: Styles for the webpage layout and logos.
- `skripta.js`: JavaScript for drawing the Canvas logo.
- `img/`: Folder containing PNG images (apple.png, iphone.png, etc.).
- Other files: Original versions and backups.
